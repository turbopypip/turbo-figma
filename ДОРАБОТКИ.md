## 01. Формат выдачи: файл вместо обязательной пагинации

- [ ] Решить, заменить ли обязательную пагинацию сохранением результата вызова в файл.

По Windows-отчёту 28 узлов потребовали 8+ вызовов при лимите страницы 24 КБ. Пользователь напомнил о прежнем подходе: результат вызова сохранялся целиком в файл.

Вариант для последующего решения: один вызов сохраняет полный результат в пределах заданной глубины в JSON-файл, а MCP возвращает путь, краткую сводку, число узлов и явные признаки неполноты. Небольшой результат можно возвращать целиком прямо в ответе. Агент читает нужные части файла или запрашивает конкретный узел. Пагинацию рассмотреть как дополнительный режим для клиентов без доступа к файлу, а не обязательный основной путь.

Перед решением учесть доступность файла агенту (локальный и удалённый MCP), размер и срок хранения результата, ограничение памяти при записи. Этот подход сам по себе не устраняет ограничение depth, неразрешённые переменные и reader busy.
