# Текст и визуальные стили (TODO 12)

Сетевой запрос `get_network_tree` возвращает `node.style` в форматах `context`
и `debug`. Нормализация выполняется после применения instance overrides.
Рабочий запрос не обращается к интерфейсу Figma. Новых зависимостей нет.

## Контракт

- `style.source`: выбранные параметры прозрачности, скруглений и обводки.
- `style.fills` / `strokes`: порядок paints, type, visible, opacity, blendMode,
  цвет RGBA; для градиентов — stops и матрица. `null` означает отсутствие
  сохранённой коллекции либо явно обозначенный лимит, а `[]` — сохранённую пустую
  коллекцию. Отсутствующие wire-поля не восстанавливаются догадками.
- `style.effects`: тип, видимость, blendMode, offset, radius, spread,
  showShadowBehindNode, цвет и blurOpType, когда они записаны в снимке.
- `style.text.base`: базовая типографика, исходные единицы, fills и CSS.
- `style.text.ranges`: полуоткрытые диапазоны `[start,end)` в UTF-16;
  текст находится в `node.text`, без повторения строки в каждом диапазоне.
  Каждый диапазон содержит styleId, эффективные source/fills/css и unresolved.
  Нулевой styleId использует базовый стиль; ненулевые ID ищутся по `styleID`,
  а не по позиции в таблице. Неуказанные свойства наследуются от базового стиля.
- `style.css`: безопасно преобразуемые значения. В `context` они также включены
  в `layout.css` и `layout.cssText`. В `debug` геометрический `layout` сохраняет
  прежний контракт, а визуальный CSS находится в `style.css`.
- `unresolved` на уровне style, text и диапазонов сообщает причины пропусков;
  `complete: false` не позволяет принять этот набор за весь рендеринг Figma.

Для текста поддержаны семейство, размер, числовой вес и наклон из fontMetaData,
line-height в px/%, letter-spacing в px/% (проценты переводятся в em), известные
значения горизонтального выравнивания, регистра, подчёркивания/зачёркивания и
slashed-zero. Вес не угадывается по названию Regular/Medium/SemiBold.
Общие для всех диапазонов CSS-свойства поднимаются на уровень узла; различающиеся
веса, размеры или цвета остаются в диапазонах. Ошибки таблицы, неизвестные ID,
несовпадение длины и границы внутри surrogate pair не превращаются в единый стиль.
Проверенный живой смешанный пример содержит BMP-текст; non-BMP границы проверены
синтетически. Иное кодирование индексов будет явно отклонено по длине/границам.

Одна видимая сплошная заливка NORMAL преобразуется в цвет текста или фон
прямоугольного контейнера. Альфа цвета умножается на opacity paint; opacity слоя
остаётся отдельным CSS-свойством. Цвета сохраняют float-точность, CSS округляется
до шести знаков после запятой. Поэтому исходный канал 242 может выглядеть как
242.000001; при сверке UI учитывается точность float32.

Радиусы прямоугольных контейнеров преобразуются в border-radius в порядке
TL/TR/BR/BL. Индивидуальные радиусы имеют приоритет над общим. Сглаживание углов
и геометрия непрямоугольных фигур не подменяются обычным border-radius.

## Явные ограничения

- Многослойные paints, градиенты, изображения, видео, паттерны, новые типы paints
  и blend modes не получают приближённый CSS. Доступные параметры сохраняются;
  image hashes, технические blobs и variable payloads не входят в обычный ответ.
- Inside/center/outside обводка сохраняет толщину, стороны, цвет, alignment,
  cap/join и dashPattern. Автоматический CSS border отсутствует: его геометрия
  и влияние на размеры требуют отдельной проверки.
- Тени и blur возвращаются параметрами дизайна. Автоматическое box-shadow/filter
  не обещается: совпадение параметров инспектора не доказывает совпадение
  растеризации, порядка смешивания и поведения behind-transparent-areas.
- AUTO line-height, variable fonts, сложная типографика, списки и абзацная
  раскладка не синтезируются. Неизвестные веса/единицы остаются unresolved.
  Вертикальное выравнивание хранится как исходное значение без CSS vertical-align.
- Привязки переменных Figma разрешаются по доступным определениям снимка:
  [network-native-variables.md](network-native-variables.md). Paints содержат
  variableBindingPresent и актуальный variableBindingUnresolved. Сопоставление с UI-kit и отдельные нативные ссылки реализованы в TODO 13: [контракт](network-variables.md).
- Пропущенные defaults и отсутствующие коллекции нельзя трактовать как нули,
  прозрачные paints или отсутствие эффектов. Это начальный снимок, не live-state.

## Ограничения ресурсов

Оба декодера сохраняют текст, индексы диапазонов, таблицу стилей и метаданные
шрифтов; glyph paths, derived layout, font digests и geometry blobs пропускаются.
Действуют прежние ограничения wire decoder и selection cache.
Нормализация ограничивает paints/effects до 128, gradient stops до 128 на paint,
font metadata до 256 и таблицу/число диапазонов до 1024. Повторяющиеся диапазоны
имеют отдельный бюджет 100000 байт. Превышение обозначается в unresolved без
ложного полного набора. Итоговый UTF-8 JSON, включая диагностику и continuation,
по-прежнему ограничен `maxBytes` (4096–150000); слишком большой узел получает
`propertiesOmitted`. Проверены продолжения без потерь/дубликатов и общий кэш
context/debug. Общая приёмка 500 МБ остаётся TODO 20.

## Приёмка 25 октября 2026

Четыре примера сверены с живым инспектором Figma View:

1. Смешанный текст: Montserrat 500/600, 48 px, line-height 48 px,
   letter-spacing −3%, uppercase, белый цвет; отдельный Span соответствует
   второму диапазону `[18,64)`.
2. Белая карточка с четырьмя DROP_SHADOW: X/Y, blur, spread, behind-transparent
   и RGBA сверены после раскрытия всех эффектов.
3. Обводка внутрь 1 px, белая, радиус 6000 px.
4. Кнопка с серым фоном и четырьмя радиусами 6 px; числовое значение радиуса
   прочитано из tooltip атрибута variable pill.

72 проверки каждого формата — без расхождений. Это контрольные примеры,
а не обещание полного визуального паритета документа. Состояние UI и снимка
совпало на наблюдаемых свойствах; равенство серверной ревизии не утверждается.
Повторная layout-проверка всей прежней ветки: 103 узла, без расхождений.
Typecheck и 181/181 тестов прошли. Self-review исправил бюджет повторяющихся
диапазонов, исключение glyph data в обоих декодерах и CSS радиусов векторных фигур.

Приватные baseline, DOM-наблюдения и полные отчёты остаются в
`.cache/figma-network/style-checks/`. В Git хранится только
[обезличенная сводка](network-style-acceptance.json).

Воспроизведение после `npm run build`:

```sh
node scripts/check-network-style.mjs artifacts/selection-2001-41847/capture.json .cache/figma-network/style-checks/live-baseline.json context
node scripts/check-network-style.mjs artifacts/selection-2001-41847/capture.json .cache/figma-network/style-checks/live-baseline.json debug
```

Baseline содержит fileKey, observationEvidence и cases с nodeId и проверками
`{path: [...], expected, tolerance?}`. Скрипт проверяет каждый ожидаемый путь,
отклоняет отсутствующие/усечённые узлы и сохраняет отчёт в управляемый кэш.
Числовая tolerance для float-цветов — 1e-6 в нормализованной шкале 0–1.
