## Формат результата

По умолчанию используется `format: context`: дерево с `id`/`parentId`,
`properties` и привычными `layout.css`/`cssText`, `sizing`, `source`, `hints`,
`unresolved`. Поля `properties` используют прежнюю структуру секции
`properties-inspection-panel`, но содержат нормализованные сетевые значения.
Wire-поля, evidence декодера и метрики остаются в `format: debug`.
Формат привязан к continuation; переключать его между страницами нельзя.
Кэш selection общий для обоих форматов и хранит необходимые внутренние данные.

- `copyText` не возвращается: измерения доступны в `measuredCss` и `geometry`,
  а применимые CSS-свойства — в `css` и `cssText`.
- `measuredCss`: width/height в px, как числовые размеры прежнего UI-парсера.
- `css`, `cssText`: применимые CSS-свойства. Для Hug/Fill измерения не выдаются
  за фиксированные width/height. `sizing` хранит режим, измерение и evidence.
- `source`: в обычном ответе — нормализованные значения дизайна; в
  `format: debug` — исходные wire-поля без подмешивания восстановленных значений.
- `geometry`: локальная матрица, перенос в координатах родителя, parent AABB,
  абсолютная матрица/позиция в canvas и положение относительно ближайшего frame.
- Top/Left/Rotation находятся в `source` обычного ответа и в `inspector`
  отладочного. Top/Left — верхний левый угол AABB относительно ближайшего frame,
  Rotation — угол в соглашении инспектора Figma (обратный знак к atan2 матрицы).
  Группы (`FRAME` с `resizeToFit`) не образуют новую систему координат.
- `constraints`: исходные ограничения по двум осям; это не автоматический CSS.
- `unresolved` (в debug — `unavailable`), `complete: false`: неприменённые/неподтверждённые возможности
  остаются явными. Полнота всего design context этим пунктом не обещается.

Fill зависит от оси родителя, grow/STRETCH и отсутствия ABSOLUTE. Для текста
учитывается `textAutoResize`. На проверенной схеме восстановлены отсутствующие
frame sizing: основная ось Hug, поперечная Fixed. Профиль ограничен SHA-256 схемы
`6518ae0a292d152a65a2a9d82ef27d8fb1f158b28c240d7aec5eb75ea93df288`;
неизвестная схема не получает эти defaults. У instances defaults применяются
после чтения определения компонента. Отсутствующие padding/gap не угадываются.

WRAP/NO_WRAP преобразуются в flex-wrap; main/counter spacing распределяются по
row-gap/column-gap с учётом направления. Отрицательное spacing сохраняется в
source и требует перекрытия, но не превращается в недопустимый CSS gap.
При распределении space-between старое spacing не выдаётся за эффективный gap.
`minSize`/`maxSize` с конечными неотрицательными значениями преобразуются в CSS.

## Компоненты и ограничения

Определения компонентов читаются адресно с диска. Полный индекс документа в RAM
не создаётся; внешний master не попадает в RAM-кэш selection. Для descendants
учитываются overrideKey/guidPath, symbolOverrides, derivedSymbolData, вложенные
переопределения, component properties видимости, текста и замены компонента.
Порядок Layers: Auto Layout — порядок wire position, остальные контейнеры —
обратный порядок рисования. Скрытые компоненты исключаются до раскрытия.

ID производного узла имеет вид `I<instance>;...;<sourceNodeId>`; sourceNodeId
сохранён отдельно. Это устойчивый путь чтения, не DOM-ID текущей сессии Figma.
Корневая ссылка запроса по-прежнему должна указывать на обычный wire node ID;
адресное открытие производного ID отдельным запросом ещё не поддерживается.

Циклы, более 32 вложенных компонентов, более 200000 посещённых узлов и контекст
переопределений больше 1 МиБ дают явную ошибку. Неподтверждённый uniformScaleFactor,
отличный от 1, также отклоняется. Отсутствующий master/неподдержанная привязка
помечаются instanceUnresolved; такой результат не проходит проверку паритета.
Grid tracks, неизвестные схемы/defaults и внешние variable aliases не объявлены
поддержанными. Grid отсутствует в контрольной ветке; прежний UI-парсер также не
имел CSS mapping для Grid. Общая поддержка компонентов остаётся TODO 14.

неудобных размеров: отсутствие/различие измерения всегда проваливает проверку.
