## Исправления после приёмки

25 октября 2026. Исправлены три найденных блокера; TODO 19 остаётся открыт
для оставшихся критериев общей приёмки.

- **Шрифты:** на однородном тексте единственный шрифт из
  `derivedTextData.fontMetaData` имеет приоритет над сохранённым `fontName`.
  Исходное имя сохраняется в `requestedFontName`, происхождение замены —
  в `fontNameProvenance`. Смешанные диапазоны и неоднозначные метаданные
  не получают угаданную замену. Это устраняет 12 расхождений типографики.
- **Цвета:** RGBA solid color variable проецируется в RGB + paint opacity,
  поэтому alpha не умножается повторно на уже сохранённую opacity.
  Прозрачность слоя остаётся отдельной. Для non-normal blend добавлено
  `paintColor` — исходный цвет краски до смешивания; он не выдаётся за
  готовый CSS фон. Сравнитель теперь использует этот цвет, как инспектор,
  сохраняя предупреждения о неподдержанной композиции. Все 79 цветовых
  расхождений в сохранённой выборке устранены либо объяснены этим различием.
- **UI при наблюдении:** pending UI больше не запрещает delta-пакеты.
  Проверки сессии, очереди, классификация служебных сообщений и блокировка
  конкурирующих изменений в reader/store сохранены. Регрессионный тест

## Исправление лимита служебного трафика и финальные проверки

служебные сообщения. Теперь он использует безопасный целочисленный диапазон,
а 128 пакетов / 8 МиБ ограничивают только изменения документа. Проверенные
служебные сообщения не сохраняются в индексе и не расходуют этот бюджет.
Проверки размера отдельной записи, последовательности, сессии и очереди
сохранены. Ошибки схемы и переполнения очереди разделены; статус MCP сохраняет
`captureError` и `lastDisconnect` до следующего подключения.

общим объёмом больше 8 МиБ при ожидающем UI-запросе, сохраняет старый
continuation и затем применяет изменение узла. Невалидный sequence по-прежнему
разрывает захват с точной диагностикой. Лимит применённых изменений сохранён.

Инструкция MCP теперь прямо требует продолжать полный обход до null, не
заканчивать ответ при ненулевом continuation и не выдавать предположение о
размере контекста за фактическую ошибку клиента. Это инструкция модели,
а не гарантия её поведения или доступности провайдера.
