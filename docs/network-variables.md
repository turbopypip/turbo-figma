# Переменные и UI-kit (TODO 13)

`get_network_tree` принимает абсолютный локальный `variablesFile` с `.scss`/`.css`.
При отсутствии параметра MCP использует `variablesFile` из конфигурации.
Поддержаны managed snapshot и legacy captureFile, context и debug.
Основной `get_design_context` по-прежнему использует UI (переключение — TODO 18).

## Вычисленные совпадения

Используется существующий `mapContextVariables`: категории space, size-text,
font-weight, font-family, radius, border-width и точные цвета. Это сопоставление
значений с локальным UI-kit, а не доказательство исходной привязки Figma.

- `layout.css` и `style.css`, включая `style.text.base` и каждый текстовый диапазон,
  содержат применимые `var(--...)`. Каждый такой объект сохраняет исходный CSS
  в `resolvedValues`, диагностику — в `variableMatching`.
- Неизменными остаются исходные параметры `source`, paints, геометрия, sizing,
  границы текстовых диапазонов и нативные ссылки. Hug/Fill не превращаются в Fixed.
- Совпадения помечены `source: ui-kit-value-match`. Нецветовые категории требуют
  единственного кандидата; несколько кандидатов дают `ambiguous`, отсутствие —
  `not-found`. Неподдержанные свойства остаются буквальными (`unsupported`).
- Для цветов сохранено прежнее правило первого точного литерала в порядке файла;
  алиасы и `--gos-znak-*` исключены. При нескольких цветовых кандидатах
  `status: matched` сопровождается `ambiguous: true` и
  `selectionPolicy: first-literal-color`. Это явно обозначенный выбор по правилу.
- Сравнение цветов точное, включая alpha. Float-значения сети не округляются
  дополнительно ради совпадения с 8-bit HEX: близкий цвет может дать `not-found`.
- Без файла CSS остаётся буквальным; `variableMatching.enabled: false` на уровне
  ответа. Ошибка чтения/разбора файла не превращается в тихое отключение подбора.

Сохраняются ограничения прежнего парсера: плоские `:root`, без исполнения Sass,
импортов и выбора тем; максимум 2 МиБ. Сетевой путь дополнительно ограничен
8192 переменными и 256 символами имени. Превышение даёт ошибку. На одно совпадение
передаются первые 32 кандидата, полный `candidateCount` и `candidatesTruncated`;
решение об однозначности использует полный список, а не усечённый.

## Нативные привязки Figma

`style.nativeBindings` имеет `source: figma-wire`, `references`, `unresolved`
и `complete: false`. Из проверенной схемы сохраняются `variableConsumptionMap`
и наблюдаемые `*Var` поля paints/effects; также учитываются записи таблицы стилей
текста. Для ALIAS с локальным GUID передаётся `variableId`, расположение и тип.
Внешние/неподдержанные ссылки явно остаются неразрешёнными. Список ограничен
128 ссылками и 128 просматриваемыми записями на коллекцию/таблицу.

Определения, коллекции, активные/унаследованные режимы и выражения не разрешаются;
имена нативных токенов не угадываются по UI-kit. Отсутствие наблюдаемой ссылки
не доказывает отсутствие привязки. Вложенные ссылки градиентов и сложные структуры
не объявлены полностью поддержанными. Поля scalar/text/symbol сохраняются для
существующего механизма component properties; выражения и тяжёлые variable payloads
отбрасываются. Значения дизайна берутся из сохранённых полей узла, без подмены
значениями из определения переменной.

## Пагинация, кэш и ограничения

Файл перечитывается на каждый запрос. Подписанное продолжение привязано к пути,
разобранным значениям, порядку деклараций и информации об алиасах. Изменение
влияющих на подбор данных требует начать обход заново; комментарии без изменения
результата разбора не инвалидируют продолжение. Передавайте тот же `variablesFile`
на каждой странице (либо используйте неизменную настройку сервера).

Подбор выполняется над копией результата, после чтения selection cache: смена
файла не загрязняет кэш значениями UI-kit. Файл переменных целиком модели не
передаётся. Нормализация одного узла ограничена 100000 байт учтённых объектов;
превышение приводит к явному `propertiesOmitted`. Полный ответ вместе с подбором
и continuation проверяется на `maxBytes`; пагинация продолжает обход без потерь
ID. Общая RAM-приёмка и Windows остаются TODO 20.

## Проверка

Unit/integration tests проверяют точные/неоднозначные/отсутствующие совпадения,
цветовую политику, смешанный текст, сохранение исходных значений, оба декодера,
лимиты, недействительное продолжение при смене UI-kit, повтор с неизменённым
selection cache, оба источника и формата. Через настоящий stdio MCP проверены
конфигурационный файл и переопределение параметром запроса.

Для воспроизводимой сверки сохранённой selection:

```sh
npm run build
node scripts/check-network-variables.mjs CAPTURE_JSON VARIABLES_SCSS SELECTION_URL context
node scripts/check-network-variables.mjs CAPTURE_JSON VARIABLES_SCSS SELECTION_URL debug
```

Скрипт сопоставляет все ID и исходный CSS до/после подбора, проверяет диапазоны,
нативные ссылки, отсутствие пропущенных свойств и лимит каждой страницы.
Отчёты остаются в `.cache/figma-network/variable-checks/`. Локальный
`test-ui-kit.variables.scss` — тестовый набор из предыдущей работы, не production
UI-kit. Replay не заменяет новую живую UI-приёмку TODO 19.
