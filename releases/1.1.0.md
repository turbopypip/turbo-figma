## Русский

### Что нового

- Готовые сборки Rust-сервера для Windows x64, Linux x64 и macOS Apple Silicon. Компиляция и установка Rust больше не нужны.
- Русский и английский интерфейс расширения: кнопки, статусы подключения и захвата, сообщения кеша, подсказки значка. Язык выбирается по языку браузера.
- README на русском и английском с переключателем и инструкциями для Chrome, Edge, Brave, Opera и Vivaldi.
- Префикс инструментов в Kilo изменён на `turbo_figma_`, например `turbo_figma_get_design_context`.

### Установка

| Система | Файл в Assets ниже |
| --- | --- |
| Windows x64 | `turbo-figma-v1.1.0-windows-x64.zip` |
| Linux x64 (Ubuntu 22.04 или совместимый) | `turbo-figma-v1.1.0-linux-x64.tar.gz` |
| macOS Apple Silicon | `turbo-figma-v1.1.0-macos-arm64.tar.gz` |

1. Скачай **архив своей ОС из Assets**, а не автоматически добавленные GitHub архивы Source code. Распакуй в постоянный каталог.
2. Установи Node.js 20.12+ для настройки. Из распакованного каталога выполни `node scripts/setup.mjs --assets /абсолютный/путь/к/ассетам`. На Windows, например: `node scripts/setup.mjs --assets 'C:\Projects\site\public\figma'`.
3. Загрузи каталог `extension/` как распакованное расширение в браузере и добавь запись из `.local/kilo.json` в конфигурацию Kilo.
4. Запусти MCP, открой Figma, нажми значок расширения и подключись с портом и секретом из `.local/pairing.txt`.

[Полная инструкция на русском](https://github.com/turbopypip/turbo-figma/blob/v1.1.0/README.ru.md). Контрольные суммы архивов — в `SHA256SUMS`.

### Обновление с 1.0.1

Останови MCP, замени сервер и расширение вместе, сохрани `.local/`. Переименуй ключ MCP-подключения в конфигурации Kilo из `turbo-figma` в `turbo_figma`. Перезагрузи расширение, перезапусти MCP и нажми «Подключить» для нового захвата. При смене каталога скопируй `.local/`, повтори setup с прежним путём к ассетам и обнови пути в Kilo.

Intel Mac и другие архитектуры пока требуют сборки из исходников. Расширение требует Chromium 125+ с API `debugger`; Firefox и Safari не поддерживаются. Сквозная работа с Figma не проверялась отдельно во всех перечисленных браузерах.

## English

### What's new

- Prebuilt Rust servers for Windows x64, Linux x64, and macOS Apple Silicon. No Rust installation or compilation required.
- Russian and English extension UI, selected from the browser language: controls, connection and capture statuses, cache messages, and badge tooltips.
- Bilingual READMEs with a language switch and installation instructions for Chrome, Edge, Brave, Opera, and Vivaldi.
- Kilo tool prefix changed to `turbo_figma_`, for example `turbo_figma_get_design_context`.

### Installation

Download your OS archive from **Assets** using the table above, not GitHub's automatically generated Source code downloads. Extract it to a permanent folder. Install Node.js 20.12+ for setup, then run:

```sh
node scripts/setup.mjs --assets /absolute/path/to/project/public/figma
```

On Windows:

```powershell
node scripts/setup.mjs --assets 'C:\Projects\site\public\figma'
```

Load `extension/` as an unpacked browser extension, merge `.local/kilo.json` into Kilo, start MCP, and connect from the extension using the port and secret in `.local/pairing.txt`.

[Full English instructions](https://github.com/turbopypip/turbo-figma/blob/v1.1.0/README.md). Archive checksums are in `SHA256SUMS`.

### Upgrading from 1.0.1

Stop MCP, replace the server and extension together, and preserve `.local/`. Rename the Kilo MCP entry from `turbo-figma` to `turbo_figma`. Reload the extension, restart MCP, and click Connect to capture again. If you move the installation, copy `.local/`, rerun setup with the same asset path, and update the generated paths in Kilo.

Intel Macs and other architectures currently require a source build. The extension requires Chromium 125+ with the `debugger` API; Firefox and Safari are unsupported. End-to-end Figma operation has not been separately verified in every listed browser.
