## Русский

Исправлены ошибки `Zstandard content size missing`, `Truncated Zstandard block` и `Expected Zstandard frame` при загрузке макетов, которые Figma передаёт с потоковым сжатием.

- Декодер сохраняет состояние Zstandard между `STREAM_START` и `STREAM_END`, включая пакеты без собственного заголовка.
- Исправление применяется к живому захвату, повторному чтению сохранённого снимка и диагностическим инструментам.
- Сохранены ограничения распакованного размера и окна сжатия, проверки целостности блоков и порядка сообщений.
- Проверено на полном записанном потоке из 28 сообщений с 43 599 узлами и на новом живом захвате Figma. Добавлены регрессионные тесты.

### Обновление с 1.1.0

Скачай архив своей ОС из Assets: Windows x64, Linux x64 или macOS Apple Silicon. Останови MCP, замени сервер и расширение, сохрани каталог `.local/`. Перезагрузи расширение, перезапусти MCP и нажми «Подключить» для нового захвата. Формат конфигурации и имена инструментов не изменились. Контрольные суммы архивов находятся в `SHA256SUMS`.

[Инструкция на русском](https://github.com/turbopypip/turbo-figma/blob/v1.1.1/README.ru.md).

## English

Fixes `Zstandard content size missing`, `Truncated Zstandard block`, and `Expected Zstandard frame` when loading designs that Figma sends using streaming compression.

- Preserves the Zstandard decoder state between `STREAM_START` and `STREAM_END`, including continuation packets without their own frame header.
- Applies to live capture, stored snapshot replay, and diagnostic tools.
- Retains decompressed size and window limits, block integrity checks, and message ordering validation.
- Verified against a complete recording of 28 messages containing 43,599 nodes and a fresh live Figma capture. Includes regression tests.

### Upgrading from 1.1.0

Download your OS archive from Assets: Windows x64, Linux x64, or macOS Apple Silicon. Stop MCP, replace the server and extension, and preserve `.local/`. Reload the extension, restart MCP, and click Connect for a fresh capture. Configuration format and tool names are unchanged. Archive checksums are in `SHA256SUMS`.

[English instructions](https://github.com/turbopypip/turbo-figma/blob/v1.1.1/README.md).
